Nouns

Algorithm (Algoritmo)

A set of ordered steps used to solve a problem or perform a calculation. Example: This algorith is very messy

Server (Servidor)

A powerful computer that stores data and distributes it to other machines in a network. Example: The server is on

Database (Base de Datos)

An organized system used to store and manage large amounts of electronic information. Example: This database is a disaster

Firewall

A security system that monitors and blocks unauthorized access to a network. Example: You can't download that file, it'd go over the firewall

Architecture (Arquitectura)

The fundamental structure and structural organization of a computer system, software application, or network, defining how its internal components interact and communicate with one another. Example: The architecture of this net is a star topology

Repository (Repositorio)

A centralized digital storage location where developers manage, store, track, and maintain source code, documentation, and asset files throughout the software development lifecycle. Example: Download it from the repository

Latency (Latencia)

The time delay between the initiation of a network or system request and the receipt of a response, typically measured in milliseconds. Example: The latency is so high

Middleware

Software that acts as a bridge or translation layer between an operating system or database and applications, enabling seamless data management and communication. Example: Between the hardware and software, is the middleware
