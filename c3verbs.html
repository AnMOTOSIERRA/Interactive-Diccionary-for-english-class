Verbs

Code (Programar)

To write code with instructions for a computer to execute. Example: Code this part of the program and i'll handle the rest

Encrypt (Encriptar)

To hide data using a code so that only authorized people can read it. Example: We have to encrypt this sensible data

Compile (Compilar)

To translate code written by a programmer into a language that the machine understands. Exameple: This code doesn't compile and i don't know why

Refactor (Refactorizar)

To restructure, clean, and optimize existing source code without changing its external behavior, improving its readability, maintainability, and efficiency. Example: This module is so slow, I did read the code and You can refactor it.

Deploy (Despegar/Sacar al mercado)

The process of inspecting, testing, transferring, and activating a completed software application or update from a development environment to a live production server. Example: We're deploying this application tomorrow.

Encapsulate (Encapsular)

To bundle data attributes and the methods operating on that data within a single unit or class, restricting direct external access to internal state details. Example: Encapsule this data.

Parse

To analyze a string of symbols, code, or structured text according to formal syntax rules, transforming it into a data structure suitable for execution or processing.
