Adverbs

Locally (Localmente)

Within a specific, restricted area or on the current physical device, rather than globally, remotely, or over a network. It means an action is happening on the machine you are physically using or where the software is currently running, without internet or cloud dependency. Example: I'm making the script work locally

Asynchronously (Asíncronamente)

The API data is fetched asynchronously. doing something without waiting for another event or task to finish at the same time. Operating or occurring at different times, speeds, or phases rather than simultaneously. Example: Our support service should work asynchronously from now on

Recursively (Recursivamente)

Describes a process, function, or rule that applies to itself or calls itself repeatedly. • It refers to a method or function that invokes itself with a smaller sub-problem until it reaches a defined base case (stopping condition). The script should make the variable work recursively.

Dynamically (Dinamicamente)

An adverb that describes a process, action, or system that changes, adapts, or updates automatically in response to a situation, rather than being fixed or predetermined. It means something happens at runtime (while the program or website is actively running). For example, a dynamically updated website changes its content in real-time based on what the user clicks, without needing a full manual redesign or page reload. Example: The quests script has to work dynamically, otherwise it would be repetitive.

Statically (Estaticamente)

Something that is fixed, unchanging, or determined beforehand, rather than altering during a process. It is the direct opposite of dynamically. Example: Our storage system gets the amount of the items statically before showing said items

Automatically (Automaticamente)

Action or process that happens by itself, without human intervention, or as an involuntary, natural reaction. • It means a system, script, or machine executes a task on its own based on a trigger. For example, your phone automatically updates its apps overnight, or a smart light turns on when you walk into a room. Example: our system should register all users by ip automatically

Simultaneously (Simultaneamente)

is an adverb that means at the exact same time or concurrently. It describes two or more actions happening at the very same instant, or a single action occurring in multiple places at once. • It refers to parallel processing or synchronized operations. For instance, a phone's dual-camera system can simultaneously capture a wide-angle shot and a telephoto video, or a server can handle thousands of user requests simultaneously. Example: the servers should be able to keep the players and NPCs working simultaneously

Remotely (Remotamente)

From a distance or via a network connection, without being physically present at the location or using the local hardware. It means accessing a server, computer, or service over the internet or a network. Example: yeah you can access the company's server remotely
